# منظومة واستوديو محتوى «مذاكراوي» 🚀
### المنظومة الشاملة لإدارة وصناعة المحتوى التحفيزي والسلوكي لطلاب الثانوية العامة بالذكاء الاصطناعي

> **الهدف:** توفير محتوى نفسي، أدبي، وسلوكي غير تقليدي لطلاب الثانوية العامة (تالتة ثانوي)، مبني على علم النفس المعرفي وحل المشكلات الجذرية بدون تنمية بشرية معلبة أو نصائح خاوية.

## المنصة الحالية: «مشكلة وحل» — نوفمبر ٢٠٢٦

**٧ بوستات مباشرة عن مشكلات الطلاب المتكررة وحلولها، وبوست قصصي مستقل واحد فقط.** استُبدلت السلسلة الروائية بالكامل. المواعيد: ٦، ٩، ١٣، ١٦، ٢٠، ٢٣، ٢٧، ٣٠ نوفمبر ٢٠٢٦، الساعة ٨ مساءً بتوقيت القاهرة.

الموضوعات: الموبايل، بطء الإنجاز داخل المهمة الحالية، الحيرة بين المدرسين، النسيان، النوم والإرهاق، الخوف من البداية، وفهم الشرح دون القدرة على الحل. الاختيار مبني على تصنيفات ١٠٠ رسالة عامة بدون أسماء؛ التكرار وحدوده موثّقان في [ملاحظات التحرير](docs/weekly-editorial-notes.md). ملف الطلاب والرسائل الخاصة غير منشورة.

- الموقع: https://motivaion.muzakrawy.workers.dev/weekly
- [بوستات نوفمبر كاملة](weekly/november-2026.md)، [التقويم](weekly/schedule.csv)، [حزمة النصوص](weekly/season.zip).
- نسخ كامل لتليجرام، TXT، صورة اختيارية باللوجو، بحث وفلاتر الأسبوع ونوع البوست. علامات النشر محلية ولا تنشر شيئًا تلقائيًا.
- النصوص تناسب رسالة تليجرام واحدة، وتتجاوز حد تعليق الصورة المعتاد. خيار المعاينة يضيف رابط البوست؛ ظهور الصورة يعتمد على إعدادات تليجرام.
- مكتبة الصور السابقة أُعيد استخدامها حسب موضوع كل بوست. الصور تُحمّل منفردة؛ حزمة ZIP للنصوص.

المصدر `weekly/episodes.json`: حرّر `intro` و`solution` و`example` و`closing` والعنوان. `kind` هو `advice` أو `story`، و`imageId` رقم الرسم المناسب. الأمر التالي يعيد تجميع البوستات والملف والتقويم والصفحات والحزمة:

```sh
python scripts/build-weekly.py
npm test
STUDIO_URL=http://127.0.0.1:3456 node tests/weekly-browser.cjs
```

اختبار المتصفح يحتاج خادمًا يعمل وPlaywright وChromium. مصدر الرسومات المتجهة ٥–٨ في مكتبة الصور هو `scripts/render-weekly.cjs`، ويحتاج نفس أدوات المتصفح عند إعادة تصديرها. أرقام الصور لا يلزم أن تطابق أرقام البوستات.

القاعدة: تنفيذ الموجود في جدول الطالب بأفضل أداء متاح، دون إنشاء جدول أو تعديله أو تكليف كبير. المحتوى أدناه أرشيف؛ خطة النشر الحالية هي الثمانية بوستات أعلاه.



## حملة نوفمبر الجديدة — «شغّل اللي في إيدك»

- لوحة نوفمبر: افتح مسار `/november` بعد `npm start`، أو زر «نوفمبر الجديد» في الاستوديو.
- [الملف الكامل](mozakrawi-november-2026-complete.md): ٣٠ رسالة + كبسولات وستوري + ١٢ كاروسيل + ٤ نصوص ريلز وردود للمشرفين.
- [سجل النشر](november/schedule.csv): تواريخ نوفمبر ٢٠٢٦ بتوقيت القاهرة، سجل تحريري عام يحتاج مواءمة مع قالب منصة الجدولة.
- الديجرامات داخل `november/` بصيغتي SVG وPNG، مقاس 1080×1350. علامات النشر في اللوحة محلية للمتصفح ولا تقوم بالنشر الفعلي.
- مصدر الرسائل `november/posts.txt`. بعد تعديله، شغّل `python scripts/build-november.py` لتحديث JSON وMarkdown وCSV وSVG. إذا غيّرت الديجرامات، أعد تصدير SVG إلى PNG بحجمها الأصلي باستخدام متصفح أو محرر رسوم يدعم العربية.
- التحقق: `node --test tests/november.test.mjs` (يشغّل خادمًا مؤقتًا على منفذ متاح، ويتحقق من التقويم والملفات والروابط).

قواعد الحملة: تنفيذ الموجود في جدول الطالب بأفضل أداء متاح؛ دون طلب إنشاء جدول أو تعديله أو إضافة تكليف كبير. أُضيفت القواعد لطلبات التوليد في الاستوديو وعلى الخادم. المحتوى القديم محفوظ كأرشيف وقد يختلف عن هذا التوجّه؛ راجعه قبل إعادة نشره. التوليد الخارجي يحتاج مفتاح Gemini صالحًا وإتاحة وجهته الشبكية؛ وجود المحتوى والديجرامات لا يعني نجاح اتصال API.

### حزم الصور الجاهزة

زر «تحميل حزمة النشر كاملة ZIP» في لوحة نوفمبر يجمع النصوص وسجل النشر و٧١ شريحة PNG للكاروسيلات الـ١٢ والديجرامات الثمانية. ويمكن معاينة الشرائح وتحميل كل كاروسيل منفصلًا من بطاقته. الصور مرقّمة بترتيب رفعها، 1080×1350؛ المصادر HTML وSVG مرفقة للتعديل.

لتحديث الحزمة بعد تحرير المحتوى، بالترتيب:

```sh
python scripts/build-november.py
CHROMIUM_PATH=/usr/bin/chromium node scripts/render-november.cjs
python scripts/package-november.py
node --test tests/november.test.mjs
```

تصدير الصور يحتاج Playwright ومتصفح Chromium وخطًا يدعم العربية (استُخدم Noto Sans Arabic). الحزم مثبتة في بيئة المشروع الحالية؛ غيّر `CHROMIUM_PATH` حسب جهازك أو احذفه لاستخدام متصفح Playwright المثبت. تشغيل الاستوديو نفسه ما زال لا يحتاج حزمًا خارجية.

لاختبار المعاينة والتحميل والنسخ وفلاتر الكنترول على خادم يعمل: `CHROMIUM_PATH=/usr/bin/chromium node tests/november-browser.cjs`. يمكن تحديد عنوان خادم الاختبار في `STUDIO_URL`. يستخدم الاختبار متصفحًا معزولًا ولا يغيّر سجل النشر في متصفحك.

## النشر على Cloudflare Workers — motivaion

الاسم مضبوط على `motivaion` حسب الطلب. نسخة Workers تقدم الاستوديو وصفحات الرواية ونوفمبر والملفات القابلة للتحميل. تُحفظ تعديلات كل زائر ومفتاح Gemini في متصفحه؛ لا يوجد ملف مستخدمين مشترك أو مفتاح Gemini عام على الموقع. نسخة Node المحلية تحتفظ بسلوك الحفظ المحلي السابق.

التجهيز والنشر من جذر المشروع:

```sh
npm ci
npm test
npm run build:cloudflare
npx wrangler deploy --dry-run
npm run deploy:cloudflare
```

الخطوة الأخيرة تحتاج `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN` في إعدادات البيئة الآمنة. استخدم توكن محدودًا للحساب المقصود بصلاحية **Account → Workers Scripts → Edit**، مع صلاحية قراءة الحساب إذا احتاج اختيار الحساب. لا تضع التوكن في Git أو في ملف إعدادات النشر. يمكن لحسابك الشخصي استخدام `npx wrangler login` بدل التوكن عند العمل من جهازك.

المخرجات العامة تُبنى في `dist/cloudflare` بقائمة ملفات محددة؛ لا يتم رفع `.env` أو `studio-user-data.json` أو كود الخادم المحلي. الحزمة كاملة أقل من حد حجم الملف الواحد في Workers Static Assets. المسار الرئيسي `/` و`/weekly` و`/reader` لمنصة بوستات نوفمبر؛ `/studio` و`/november` و`/series` للأرشيف. يعرض Wrangler عنوان النشر الحقيقي عند نجاحه؛ لا نفترض اسم نطاق الحساب مسبقًا.

للتجربة محليًا استخدم `npm run dev:cloudflare`. الاختبارات المكتملة تشمل بناء Worker، صفحات المحتوى والتحميل، معاينة الشرائح، وعدم إرسال مفاتيح المتصفح أو تعديلاته إلى مخزن مشترك. اختبارات Gemini تستخدم استجابات اختبارية؛ نجاح الاتصال الحقيقي يتطلب مفتاح المستخدم الصالح.

**النشر الأساسي — ٥ نوفمبر ٢٠٢٦:** Worker باسم `motivaion` على https://motivaion.muzakrawy.workers.dev. يعرض أمر النشر معرّف الإصدار عند كل تحديث. التحقق المباشر من الرابط العام داخل بيئة العمل يحتاج السماح بالنطاق `motivaion.muzakrawy.workers.dev` في إعدادات الشبكة.

أمر النشر يزيل تلقائيًا الفراغات والأسطر الزائدة حول معرّف الحساب دون تغيير بيانات الاعتماد. حزمة نوفمبر الكاملة أصبحت نحو ٦ ميجابايت بعد حذف نسخ ZIP المتداخلة المكررة؛ تظل كل الصور والنصوص موجودة، والحزم اليومية المنفصلة متاحة. الروابط داخل نسخة الخطة المرفقة بالحزمة تشير لمصادر الكاروسيلات الموجودة بجوارها.
